# MUREOP Brand Website Master Plan

— 무렵 자사몰 구축을 위한 전략 문서.
작성 기준: 제공된 브랜드 기획서. 임의로 만들어낸 사실 없음. 미확정 정보는 **[확인 필요]**로 표시.

각 항목은 **왜 필요한가 → 어떻게 구성할 것인가 → 실제 사이트에서는 어떻게 보여야 하는가** 순서로 설명합니다.

---

## 1. 브랜드 핵심 분석

**왜 필요한가** — 사이트의 모든 결정(레이아웃, 카피, 버튼 문구)은 브랜드 정의에서 출발해야 흔들리지 않습니다.

**어떻게** — 무렵의 핵심은 "향"이 아니라 "시간"입니다. 경쟁사가 향료·조향사·헤리티지를 팔 때, 무렵은 '○○ 무렵'이라는 이름으로 **놓친 순간**을 팝니다. 차별점이 제품이 아니라 언어에 있으므로, 웹사이트는 이미지보다 **문장과 여백**이 주인공이 되는 구조여야 합니다.

**사이트에서는** — 첫 화면에 제품 스펙이 아니라 "흘러가는 시간의 한 순간을, 공간에 걸어둡니다"라는 문장이 먼저 보입니다. 제품 설명도 향료 나열이 아니라 장면 묘사로 시작합니다.

## 2. 웹사이트의 역할

**왜** — 자사몰은 판매 채널 중 하나가 아니라 브랜드의 본진입니다. 카카오 선물하기·스마트스토어에서는 불가능한 경험(서사, 향 탐색, 리필 철학)을 여기서만 제공해야 자사몰에 올 이유가 생깁니다.

**어떻게** — 우선순위: ① 브랜드 인식 → ② 향 이해 → ③ 제품 신뢰 → ④ 구매 전환 → ⑤ 리필 재구매 → ⑥ 팬 형성. 광고(Instagram/Meta) 유입자가 브랜드를 처음 만나는 상황을 기본 시나리오로 설계.

**사이트에서는** — 홈은 "브랜드 → 향 → 제품 → 구매" 순서로 흐르고, SALE 배너·쿠폰 팝업은 존재하지 않습니다.

## 3. 핵심 타깃

- **Core**: 25–34세 여성, 1인 가구·신혼, 월 가처분소득 150–300만 원, 인스타그램·오늘의집 소비층. 논픽션·그랑핸드를 알지만 6만 원 이상은 부담.
- **확장 1**: 선물 구매자(집들이·생일·기념일) — 실사용자가 아니므로 "실패하지 않을 선택"이 필요.
- **확장 2**: 30대 중후반 여성, 공간 연출·셀프 선물.
- **확장 3**: 감도 높은 남성 — 젠더리스 디자인 + 우디·머스크(해 질 무렵)로 유입.
- **제외**: 1만 원대 가성비 소비자, 럭셔리 헤리티지 중심 소비자.

**사이트에서는** — 모바일 퍼스트(인스타 유입), 선물 전용 페이지, '해 질 무렵'에 "선물 · 젠더리스" 라벨을 명시.

## 4. 고객 구매 심리

**왜** — 온라인 디퓨저의 최대 장벽: **향을 맡아볼 수 없다**. 이 불안을 해소하지 못하면 어떤 디자인도 전환되지 않습니다.

**어떻게** — 3중 안전장치: ① 이름만으로 장면이 그려지는 네이밍('비 갠 무렵'), ② 장면→감각→향→공간 구조의 향 설명, ③ 실패 비용을 낮추는 기프트셋(3종 미니로 먼저 경험).

**사이트에서는** — "향을 맡아볼 수 없어도 괜찮습니다. 붙잡고 싶은 순간을 하나 고르면 됩니다."라는 문장이 향 선택 UX의 입구가 됩니다.

## 5. 경쟁 브랜드 분석

> 실제 경쟁사 사이트 정밀 분석은 런칭 전 별도 수행 권장. 아래는 공개된 포지셔닝 기준의 방향 분석입니다.

| 브랜드 | 가져올 것 | 따라 하지 말 것 |
| --- | --- | --- |
| 논픽션 | 절제된 타이포·여백, 정제된 상세페이지 구조 | 6만 원대 가격 문법, 갤러리형 연출 |
| 그랑핸드 | 한국어 네이밍의 힘, 담백한 카피 | 오프라인 스토어 중심 서사 |
| 탬버린즈 | 강한 비주얼 아이덴티티의 일관성 | 아트·오브제 중심의 과잉 연출, 모델 화보 |
| 오이뮤 | 사물·이야기 중심 브랜딩 | 문구·잡화적 톤 |
| APFR | 향조 정보의 정밀함 | 일본 헤리티지 차용, 럭셔리 문법 |

**결론** — 무렵의 기회: 경쟁사 누구도 "시간"을 정면에 두지 않습니다. 향 이름이 카테고리(우디/시트러스)이거나 외국어일 때, '비 갠 무렵'이라는 한국어 다섯 글자는 그 자체로 차별화입니다.

## 6. 무렵의 차별화 포인트

1. **네이밍이 곧 제품 설명** — '○○ 무렵' 시스템. 광고 헤드라인, 선물 카드 문구까지 대체.
2. **한국어 우선의 건조한 서정** — 수입 브랜드 흉내가 아닌 문체.
3. **리필 구조** — 3–5만 원대에서 리필 시스템을 브랜드 철학("다시 걸어두기")으로 끌어올린 브랜드는 드묾.
4. **정가 정책** — 할인 없는 구조가 오히려 신뢰 신호.

## 7. 사용자 Journey

```
Instagram/Meta 광고 (장면 카피 + 정물 컷)
→ Landing (홈 또는 제품 상세)
→ 브랜드 인지 (Hero 문장 3초)
→ 향 탐색 (세 가지 무렵 / 나의 무렵 찾기)
→ 비교·확신 (비교표, 향의 장면, 상세 정보)
→ 구매 (본품 49,000 / 선물 기프트셋 69,000)
→ 사용 (2–3개월 추정 [확인 필요])
→ 리필 (29,000, "다시 걸어두기")
→ 선물·리뷰·팬
```

이탈 위험 지점과 대응: 랜딩 3초(Hero 문장+정물 한 컷으로 즉시 인지) / 향 선택 망설임(찾기 UX + 기프트셋) / 가격 확인 순간(용기·리드·리필 구조로 가치 설명) / 결제 직전(스티키 CTA로 동선 단축).

## 8. 사이트맵

```
Home
├── Fragrance  — 세 가지 무렵 (비교 + 찾기)
│   ├── 여름 끝 무렵 (Product Detail)
│   ├── 비 갠 무렵 (Product Detail)
│   └── 해 질 무렵 (Product Detail)
├── Gift       — 선물 (기프트셋 중심)
├── Refill     — 리필 (다시 걸어두기)
├── About      — 무렵에 대하여
└── (Phase 2+) Journal/Moments — 콘텐츠 준비되면 개설
```

Journal은 지금 만들지 않습니다. "콘텐츠를 위한 콘텐츠 금지" 원칙 — Instagram·SEO 콘텐츠가 실재할 때 개설.

## 9. Homepage 전체 구조

| # | 섹션 | 답하는 질문 | 핵심 카피 | CTA |
| --- | --- | --- | --- | --- |
| 1 | Hero | 무엇인가 | "흘러가는 시간의 한 순간을, 공간에 걸어둡니다" + "지금은, ○○ 무렵"(시간 인식) | 세 가지 무렵 보기 |
| 2 | 브랜드 서사 (다크) | 왜 다른가 | "무렵은 향을 팔지 않습니다" | 무렵에 대하여 |
| 3 | 세 가지 무렵 | 어떤 제품 | 카드 3장: 이름·장면 한 줄·향조·가격 | 제품 상세 |
| 4 | 나의 무렵 찾기 | 무엇을 고르나 | "붙잡고 싶은 순간을 하나 고르면 됩니다" | 추천 결과 → 상세 |
| 5 | 제품 신뢰 | 왜 믿나 | 무광 유리 · 리드 5개 · 230mL | — |
| 6 | 리필 | 구매 후엔 | "다시 걸어두기" 29,000원 | 리필에 대하여 |
| 7 | 선물 | 확장 진입 | "어떤 향을 좋아할지 모르겠다면" | 선물 준비하기 |
| 8 | 클로징 (다크) | 왜 지금 | "이번에는, 붙잡아 두어도 좋겠습니다" | 향을 고르기 |

각 섹션은 "다음 섹션으로 넘어갈 이유"(궁금증 → 제품 → 선택 → 신뢰 → 지속 → 확산)를 하나씩 남기도록 배열.

## 10. Product / Fragrance UX

**왜** — 필터가 많아지면 쇼핑몰처럼 보입니다. 3개 제품에 필터는 과잉.

**어떻게** — ① 카드(장면 한 줄 + 향조 + 역할 라벨) ② 비교표(분위기/핵심 향/시간/공간/추천) ③ "나의 무렵 찾기": 검색 필터가 아니라 **순간을 고르는 질문** 형식의 칩 6개(순간 3 + 공간 3). 클릭 즉시 하나의 향과 이유를 제시.

**사이트에서는** — fragrance.html에 카드 → 표 → 찾기 → (그래도 못 고르면) 기프트셋 순의 안전망 구조.

## 11. Product Detail 구조

위에서 아래로: 정물 컷 + 구매 정보(이름·한 줄·향조·가격·본품/리필 옵션·CTA) → **향의 장면**(다크 섹션, 장면→감각→향) → 향조 3열(노트별 한 줄 해석) + 놓이는 자리(시간/공간/추천) → 아코디언(사용법·관리/주의·성분/제조 [확인 필요]·배송/반품 [확인 필요]·리뷰) → 리필 크로스셀 → 다른 무렵 2종 + 기프트셋.

데스크톱은 구매 정보가 sticky(스크롤해도 고정), 모바일은 하단 스티키 CTA. **발향 전개·사용 기간 등 정량 정보는 실측 전 기재하지 않고 [확인 필요]로 노출**했습니다.

## 12. Gift UX

선물 구매자의 4대 불안과 해소:

| 불안 | 해소 |
| --- | --- |
| 취향을 모른다 | 기프트셋 = 3종 미니, "고르는 일은 받는 사람의 몫" |
| 실패하면 어쩌나 | 이름이 설명을 대신 ("해 질 무렵"은 카드 문구가 됨) |
| 가격이 애매하다 | 69,000원 = 집들이·생일·기념일 표준가 포지션 명시 |
| 포장·배송 | 포장 사양·도착일 선택 **[확인 필요]** — 확정 후 게시 |

이미 취향을 아는 구매자를 위해 "받는 사람의 순간을 이미 알고 있다면" 섹션에서 본품 단품 선물 동선도 제공.

## 13. Refill UX

"29,000원짜리 싼 재구매품"이 아니라 **다시 걸어두기**라는 행위로 설계. 흐름: 본품(처음) → 같은 자리 같은 향(계속) → 리필(다시). 철학 연결: "병은 이미 공간의 일부. 버릴 이유가 없습니다." 가격은 "본품 대비 약 41% 낮은 가격"으로만 표기 — 할인이 아니라 구조임을 전달. 교차 제안: "이번에는 다른 무렵을 채워도 좋습니다. 계절이 바뀌었을 테니까." 리필 실사용법 **[확인 필요]**.

## 14. About / Brand Story

회사 소개가 아니라 **존재 이유**: ① 서사 전문(다크, 큰 타이포, 여백) ② '무렵'이라는 말의 해석("시계가 가리키지 못하는 시간") ③ 일하는 방식 4가지(이름/물건/가격/리필) ④ 클로징 → "나의 무렵 찾기"로 순환. 연혁·대표 인사말·조향사 프로필(권위 마케팅 금지) 없음.

## 15. 콘텐츠 구조

- **지금**: 홈/향/제품 3/선물/리필/About — 구축 완료.
- **런칭 시**: 리뷰(제품 상세 내), 법적 고지(Footer).
- **Phase 2+**: Journal/Moments(계절·시간·공간 콘텐츠), 시즌 한정향 페이지.
- **원칙**: 모든 카피는 Copywriting System(§25)의 5개 층위 안에서 작성. 콘텐츠를 위한 콘텐츠 금지.

## 16. Visual Direction

정물 중심, 인물 없음. 창으로 들어오는 빛, 늦은 오후의 그림자, 무광 질감, 톤다운 컬러. 현재 사이트는 **CSS 그라디언트 장면 + 병 실루엣(SVG)**으로 연출하고 모든 자리에 "실제 촬영 이미지 교체 예정" 표시. 향별 장면 톤: 여름 끝(마른 볕의 베이지), 비 갠(흐린 회녹색), 해 질(낮은 주황-갈색). 촬영 이미지가 들어오면 클래스 교체만으로 대체 가능.

## 17. Typography

Pretendard Variable(가변 웨이트, 한국어 최적화 산세리프 — 워드마크의 산세리프 기조와 일치).

| 스타일 | 크기 | 웨이트 | 용도 |
| --- | --- | --- | --- |
| Display | clamp(2.1–3.6rem) | 300 | Hero, 서사 |
| H1 | clamp(1.7–2.6rem) | 400 | 섹션 제목 |
| H2 | clamp(1.35–1.9rem) | 400 | 하위 제목, 장면 카피 |
| H3 | clamp(1.08–1.25rem) | 500 | 카드 제목 |
| Body | 1rem / 1.75 | 400 | 본문 |
| Caption | 0.8125rem | 400 | 보조 정보 |
| Label | 0.8125rem + 자간 0.14em | 500 | 엠대시 섹션 라벨 |

가는 웨이트(300)의 큰 문장 = "건조한 서정"의 시각적 번역. `word-break: keep-all`로 한국어 줄바꿈 보호.

## 18. Color System

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| Dark | #1E1E1E | 서사 섹션 배경, Primary 버튼, 제목 |
| Text | #3A3A3A | 본문 |
| Text Soft | #6F6A63 | 보조 텍스트 |
| Accent | #8B7E6F | 엠대시 라벨, 향조, 호버 — **절제 사용** |
| Light BG | #F5F2ED | 기본 배경 |
| BG Deep | #ECE7DF | 교차 섹션 배경 |
| Line | #E8E4DE | 보더 |

추가로 `--tint`: 방문 시간대에 따라 배경에 얹히는 미세한 색(JS 제어). Accent는 면적을 갖는 배경으로 쓰지 않고 선·라벨·포인트에만 사용.

## 19. UI Design System

- **버튼**: Primary(다크 채움)/Secondary(아웃라인)/Light(다크 배경 위)/Text(밑줄 + 엠대시가 호버 시 이동 — 워드마크 모티프의 인터랙션화). 최소 높이 3rem(44px+ 터치 영역).
- **카드**: 장면 3:4 + 이름 + 장면 한 줄 + 향조 + 가격. 호버 시 4px 부상 + Accent 보더.
- **엠대시 언어**: 로고(— 무렵), 섹션 라벨(—Label), 가격 표기(리필 — 29,000원), 리스트 불릿, Text 버튼 화살표 대체. 장식이 아니라 내비게이션 문법.
- **칩/옵션/아코디언/비교표/스티키 CTA**: 전부 `css/style.css`에 토큰 기반으로 시스템화. Spacing 8px 기반 8단계.

## 20. Interaction Design

"느리지만 답답하지 않은 경험":

- 스크롤 진입 시 0.9s ease-out 등장(IntersectionObserver, 1회만).
- 시간대 인식 — 방문 시각에 따라 Hero 인사("지금은, 해 질 무렵.")와 배경 틴트가 변화. **"시간을 향으로 번역한다"는 컨셉의 웹 번역이자 이 사이트를 관통하는 단일 UX 아이디어.** 기술 비용은 JS 몇 줄, 효과는 브랜드 각인.
- 금지 준수: 패럴랙스 없음, 빠른 모션 없음, 마우스 이펙트 없음, 로딩 애니메이션 없음.
- `prefers-reduced-motion` 시 모든 모션 제거.

## 30. 최종 추천 방향

**"시간을 향으로 번역하는 브랜드답게, 사이트도 시간을 인식한다"** — 방문 시각에 따라 인사와 빛이 달라지는 조용한 장치 하나로 브랜드 컨셉을 증명하고, 나머지는 철저히 절제합니다.

- 문장이 주인공, 이미지는 장면, 색은 배경.
- 향 선택 불안은 "순간을 고르는 질문"과 기프트셋으로 해소.
- 할인 대신 리필 구조("다시 걸어두기")로 재구매를 설계.
- 쇼핑몰로 보이지 않되, 모든 화면에서 구매까지 두 번의 탭 안에 도달.

성공 기준(§48): "비싼 척하지 않는데 값이 있어 보인다" / "향을 맡아보지 않았는데 장면이 상상된다" / 그리고 무엇보다 — **"무렵이라는 이름이 기억난다."**
